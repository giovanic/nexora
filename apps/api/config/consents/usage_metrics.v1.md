# Métricas de uso

Este consentimento é opcional. Com ele, registramos como você usa o app, por exemplo quais telas abre e quais funções usa, para entender o que funciona e melhorar o produto.

## O que não entra

Fotos, refeições, valores nutricionais, atividades, dados do Strava, o seu e-mail e qualquer texto que você escrever.

## Para quê

Só para melhorar o app. Não usamos essas métricas para publicidade e não as vendemos. Hoje elas não são compartilhadas com outras empresas. Se isso mudar, pedimos um novo aceite antes.

## Por quanto tempo guardamos

- As métricas ligadas a você: o prazo será definido e informado aqui antes de a coleta começar. Elas são apagadas quando você retira o consentimento.
- O registro deste consentimento: 5 anos (prazo provisório, a confirmar na revisão jurídica).

## Se você não aceitar ou quiser retirar

Nada muda no app: todas as funções continuam disponíveis.

Retirar é tão simples quanto aceitar: em Configurações, Consentimentos. A coleta para, e as métricas ligadas a você são apagadas.
